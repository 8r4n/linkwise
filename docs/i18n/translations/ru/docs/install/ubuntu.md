# Предварительная версия модема Linkwise для Ubuntu

Linkwise предоставляет двусторонний программный модем, диагностику станции и локальную симуляцию. Маршрутизация звука и настройки передачи описаны в Station Setup.

Установщик предварительной версии не содержит `secure-transfer`. Для передачи файлов с gzip/SHA-256, общей PKI, защищённого чата и почты, а также карточек QSL с сертификатами соберите программу из исходного кода. Настройка и требования гибридного чата описаны в [руководстве по PKI](../../../../../../rust/docs/pki.md).

## Установка или обновление

Узнайте архитектуру командой `dpkg --print-architecture`. В каталоге загрузки выполните следующие команды, подставив имя подходящего пакета.

```sh
sudo apt install ./linkwise-modem_0.1.0_arm64.deb
linkwise-modemd --version
linkwise-modemd --simulate
```

APT устанавливает нужные системные библиотеки. Для обновления выполните ту же команду с новым файлом. Симуляция работает локально без радио.

## Настройка станции

Откройте `man 8 linkwise-modemd` для команд и `man 5 linkwise-station` для формата. Выбор устройств и создание `station.json` описаны в `/usr/share/doc/linkwise-modem/Station-setup.md`. Проверяйте звук от пользователя рабочего стола, чтобы был доступен текущий аудиосеанс.

## Запуск службы модема

Для настольной станции сохраните настройки в `~/.config/linkwise/station.json` и выполните следующие команды.

```sh
systemctl --user enable --now linkwise-modem.service
journalctl --user -u linkwise-modem.service
```

Для выделенной станции храните файлы настроек и профиля с владельцем-администратором в `/etc/linkwise`. Службе нужен доступ к чтению файлов и прямой доступ ALSA к указанным входу и выходу. Для одного набора устройств и портов используйте одну службу.

```sh
sudo systemctl enable --now linkwise-modem.service
sudo journalctl -u linkwise-modem.service
```

С полем `bandwidth` модем открывает порты команд и данных на loopback IPv4. Без поля командный порт выдаёт диагностику приёма в JSON. Читайте её через `nc 127.0.0.1 8300`.

## Удаление

Завершите работающие команды Linkwise и выполните `sudo apt remove linkwise-modem`. Файлы станции в домашнем каталоге сохранятся.
