# Linkwise с Winlink Express

Мастер Windows поддерживает обычные аудиоустройства и стендовый обмен сигналами без выхода в эфир. Для обычного звука выберите полосу и укажите точные имена устройств записи и воспроизведения из вывода `linkwise-modemd --audio-devices`. В Express используйте порт команд и полосу, заданные в мастере. Маршрутизация звука и управление радио описаны в [руководстве по настройке станции](../../../../../../rust/docs/modem-setup.md#run-the-two-way-modem).

Для стендовой проверки BW500 без радио создайте измерительный профиль командой `python tools/fetch-modem-profile.py` из репозитория Linkwise.

1. Откройте **Configure Linkwise for Winlink**. Введите позывной, используемый в Express. Выберите **Radio-free waveform test** и профиль BW500 в JSON, затем нажмите **Apply and start service**.
2. Используйте порт команд **8300**. Если он занят исходным VARA, укажите **18310**. Linkwise покажет порты DATA и подключения сигнальной станции. Это два порта после порта команд.
3. Подключите сигнальную станцию к указанному порту. Служба принимает одну локальную станцию. Дополнительному мосту `linkwise-modemd --virtual-audio-device` нужны раздельные виртуальные тракты ввода и вывода. Запустите мост с рабочего стола Windows, если аудиодрайвер требует сеанс входа.
4. В Express откройте **VARA HF P2P**, затем **Settings → TNC Setup**. Введите **127.0.0.1** и порт команд из мастера. Express определит порт DATA. Выберите максимум **500** для полосы и снимите флажок **Automatically launch TNC when session is opened**. Сохраните настройки и заново откройте сеанс.
5. Когда Express покажет **Ready**, введите позывной изолированного корреспондента и центральную частоту испытания. Поставьте в очередь сообщение P2P с синтетическим вложением. Сверьте SHA-256 вложения у получателя и убедитесь, что оба журнала фиксируют разрыв связи.

Если Express не соединяется, проверьте адрес и порт команд. В просмотре событий откройте **Windows Logs → Application** и отфильтруйте источник `LinkwiseModem`. Если подключение есть, но Ready не появляется, проверьте подключение сигнальной станции и согласование позывных и полосы.
