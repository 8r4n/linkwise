# Winlink Express-এর সঙ্গে Linkwise

Windows উইজার্ড নেটিভ অডিও ও রেডিওবিহীন তরঙ্গরূপ পিয়ার সমর্থন করে। নেটিভ অডিওর জন্য ব্যান্ডউইডথ বেছে নিন এবং `linkwise-modemd --audio-devices` দেখানো ক্যাপচার ও প্লেব্যাক ডিভাইসগুলোর সঠিক নাম লিখুন। Express-এ উইজার্ডের কমান্ড পোর্ট ও একই ব্যান্ডউইডথ ব্যবহার করুন। অডিও রাউটিং ও রেডিও নিয়ন্ত্রণের জন্য [স্টেশন সেটআপ নির্দেশিকা](../../../../../../rust/docs/modem-setup.md#run-the-two-way-modem) দেখুন।

রেডিওবিহীন BW500 পরীক্ষার জন্য Linkwise রিপোজিটরি থেকে `python tools/fetch-modem-profile.py` চালিয়ে পরিমাপ প্রোফাইল তৈরি করুন।

1. **Configure Linkwise for Winlink** খুলুন। Express-এ ব্যবহৃত কলসাইন লিখুন। **Radio-free waveform test** ও BW500 JSON প্রোফাইল বেছে নিয়ে **Apply and start service** ক্লিক করুন।
2. মূল VARA পোর্টটি ব্যবহার না করলে কমান্ড পোর্ট **8300** রাখুন, অন্যথায় **18310** দিন। Linkwise DATA ও তরঙ্গরূপ পিয়ারের পোর্ট দেখায়। এগুলো কমান্ড পোর্টের ঠিক পরের দুটি পোর্ট।
3. দেখানো পোর্টে তরঙ্গরূপ পিয়ার সংযুক্ত করুন। সেবা একজন স্থানীয় পিয়ার গ্রহণ করে। ঐচ্ছিক `linkwise-modemd --virtual-audio-device` ব্রিজে পৃথক ভার্চুয়াল ইনপুট ও আউটপুট পথ লাগে। অডিও ড্রাইভারের জন্য লগইন সেশন লাগলে Windows ডেস্কটপ থেকে ব্রিজ চালান।
4. Express-এ **VARA HF P2P**, তারপর **Settings → TNC Setup** খুলুন। **127.0.0.1** এবং উইজার্ডের কমান্ড পোর্ট লিখুন। Express DATA পোর্ট নির্ধারণ করে। সর্বোচ্চ ব্যান্ডউইডথ **500** বেছে নিন এবং **Automatically launch TNC when session is opened** বন্ধ করুন। সেভ করে সেশন আবার খুলুন।
5. Express-এ **Ready** দেখালে বিচ্ছিন্ন পিয়ারের কলসাইন ও পরীক্ষার কেন্দ্র ফ্রিকোয়েন্সি লিখুন। কৃত্রিম সংযুক্তিসহ P2P বার্তা সারিতে রাখুন। প্রাপকের সংযুক্তির SHA-256 মেলান এবং উভয় সেশনের লগে সংযোগ বিচ্ছেদ পরীক্ষা করুন।

Express সংযুক্ত না হলে ঠিকানা ও কমান্ড পোর্ট যাচাই করুন। Event Viewer-এ **Windows Logs → Application** খুলে `LinkwiseModem` দিয়ে ফিল্টার করুন। সংযুক্ত হয়েও Ready না দেখালে তরঙ্গরূপ পিয়ারের সংযোগ এবং উভয় দিকের কলসাইন ও ব্যান্ডউইডথ পরীক্ষা করুন।
