# Linkwise مع Winlink Express

يدعم معالج Windows الصوت المحلي وطرفًا لتبادل الموجات دون بث لاسلكي. للصوت المحلي، اختر عرض النطاق وأدخل أسماء أجهزة الالتقاط والتشغيل كما يعرضها `linkwise-modemd --audio-devices`. استخدم في Express منفذ الأوامر وعرض النطاق اللذين حددهما المعالج. راجع [دليل إعداد المحطة](../../../../../../rust/docs/modem-setup.md#run-the-two-way-modem) لتوجيه الصوت والتحكم في الراديو.

لاختبار BW500 دون بث لاسلكي، أنشئ ملف قياس باستخدام `python tools/fetch-modem-profile.py` من مستودع Linkwise.

1. افتح **Configure Linkwise for Winlink**. أدخل إشارة النداء المستخدمة في Express. اختر **Radio-free waveform test**، وحدد ملف JSON الخاص بـBW500، ثم انقر **Apply and start service**.
2. استخدم منفذ الأوامر **8300**، أو **18310** إذا كان VARA الأصلي يشغل المنفذ الأول. يعرض Linkwise منفذ DATA ومنفذ طرف الموجة، وهما المنفذان التاليان مباشرة لمنفذ الأوامر.
3. صِل طرف الموجة بالمنفذ المعروض. تقبل الخدمة طرفًا محليًا واحدًا. يتطلب الجسر الاختياري `linkwise-modemd --virtual-audio-device` مساري إدخال وإخراج افتراضيين مستقلين. شغّله من سطح مكتب Windows إذا كان برنامج تشغيل الصوت يتطلب جلسة تسجيل دخول.
4. افتح **VARA HF P2P** في Express ثم **Settings → TNC Setup**. أدخل **127.0.0.1** ومنفذ الأوامر الذي يعرضه المعالج. يحسب Express منفذ DATA. اختر **500** للحد الأقصى لعرض النطاق وألغِ تحديد **Automatically launch TNC when session is opened**. احفظ الإعدادات وأعد فتح الجلسة.
5. عندما يظهر **Ready** في Express، أدخل إشارة نداء الطرف المعزول والتردد المركزي للاختبار. ضع رسالة P2P بمرفق اصطناعي في قائمة الانتظار. تحقّق من SHA-256 للمرفق عند المستلم ومن تسجيل إنهاء الاتصال في سجلي الجلسة.

إذا تعذر اتصال Express، فتحقّق من العنوان ومنفذ الأوامر. افتح **Windows Logs → Application** في عارض الأحداث وصفِّ النتائج باستخدام `LinkwiseModem`. إذا اتصل Express ولم يظهر Ready، فتحقّق من اتصال طرف الموجة ومن توافق إشارات النداء وعرض النطاق.
