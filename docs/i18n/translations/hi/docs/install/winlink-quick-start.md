# Winlink Express के साथ Linkwise

Windows विज़ार्ड नेटिव ऑडियो और बिना रेडियो के वेवफ़ॉर्म पीयर दोनों का समर्थन करता है। नेटिव ऑडियो के लिए बैंडविड्थ चुनें और `linkwise-modemd --audio-devices` में दिखे कैप्चर और प्लेबैक उपकरणों के सटीक नाम भरें। Express में विज़ार्ड का कमांड पोर्ट और वही बैंडविड्थ चुनें। ऑडियो रूटिंग और रेडियो नियंत्रण के लिए [स्टेशन सेटअप मार्गदर्शिका](../../../../../../rust/docs/modem-setup.md#run-the-two-way-modem) देखें।

बिना रेडियो का BW500 परीक्षण करने के लिए Linkwise रिपॉज़िटरी से `python tools/fetch-modem-profile.py` चलाकर मापन प्रोफ़ाइल बनाएँ।

1. **Configure Linkwise for Winlink** खोलें। Express में इस्तेमाल होने वाला कॉलसाइन भरें। **Radio-free waveform test** और BW500 JSON प्रोफ़ाइल चुनें, फिर **Apply and start service** दबाएँ।
2. कमांड पोर्ट **8300** चुनें। यदि मूल VARA इसे पहले से इस्तेमाल करता है तो **18310** दें। Linkwise DATA और वेवफ़ॉर्म पीयर के पोर्ट दिखाता है। ये कमांड पोर्ट के ठीक बाद के दो पोर्ट हैं।
3. वेवफ़ॉर्म पीयर को दिखाए गए पोर्ट से जोड़ें। सेवा एक स्थानीय पीयर स्वीकार करती है। वैकल्पिक `linkwise-modemd --virtual-audio-device` ब्रिज को स्वतंत्र वर्चुअल इनपुट और आउटपुट मार्ग चाहिए। यदि ऑडियो ड्राइवर को लॉगिन किया हुआ सत्र चाहिए, तो इसे Windows डेस्कटॉप से चलाएँ।
4. Express में **VARA HF P2P**, फिर **Settings → TNC Setup** खोलें। **127.0.0.1** और विज़ार्ड का कमांड पोर्ट दर्ज करें। Express DATA पोर्ट निकालता है। अधिकतम बैंडविड्थ **500** रखें और **Automatically launch TNC when session is opened** का चयन हटाएँ। सहेजकर सत्र फिर खोलें।
5. Express में **Ready** दिखाई देने पर अलग-थलग पीयर का कॉलसाइन और परीक्षण की केंद्र आवृत्ति भरें। एक कृत्रिम अटैचमेंट वाला P2P संदेश कतार में डालें। प्राप्तकर्ता के अटैचमेंट का SHA-256 मिलाएँ और दोनों सत्र लॉग में डिस्कनेक्ट की पुष्टि करें।

Express कनेक्ट न हो तो पता और कमांड पोर्ट जाँचें। Event Viewer में **Windows Logs → Application** खोलें और `LinkwiseModem` से फ़िल्टर करें। यदि कनेक्ट होने के बाद Ready नहीं आता, तो वेवफ़ॉर्म पीयर और दोनों ओर कॉलसाइन तथा बैंडविड्थ जाँचें।
